# Bounce Shot Goalkeeper

A 3D table game where you bounce a ball off the floor and try to score past a goalkeeper. Pull back the sling handle and release to shoot; the ball must bounce before it reaches the goal. Play against the robot goalkeeper, or switch to manual mode and move the goalkeeper yourself. Drag to look around, pinch or use the zoom buttons to zoom, and open the Advanced drawer to tweak physics, camera, timing, sweeps and exports. Everything runs in your browser from a single `index.html`, with no network requests.
